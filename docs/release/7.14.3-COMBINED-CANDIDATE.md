# Firmware 7.14.3 release record

7.14.3 is the Bitcoin-only release candidate. It includes the signing,
storage, transport, RNG, and confirmation fixes audited for this release line.
Non-Bitcoin signing engines are excluded from the shipped artifact.

## Dependencies

- device-protocol: `bd3409106554e04eedc7b525d547a211a987ff3c`, `keepkey/device-protocol`
  `master` (merge of [PR #112](https://github.com/keepkey/device-protocol/pull/112))
- python-keepkey: `7c1c4c903af3a7f999bedca1465644e100c17f40`, `keepkey/python-keepkey`
  `master` (merge of [PR #197](https://github.com/keepkey/python-keepkey/pull/197))
- trezor-firmware: `cdc05bebe9e6989cf711e1b5bea6324fd09f848e`

Both dependency pins are the human-reviewed upstream master commits.

## Release gates

- Native firmware, board, and crypto tests
- Python host integration against the Bitcoin-only emulator
- ARM release build with the 16 KiB runtime SRAM floor
- Reproducible artifact manifest and checksum verification
- Secret scan, submodule validation, static analysis, and formatting
- Physical OLED and signed-upgrade checks before release signing

The canonical pull request records the exact-head CI runs and review status.

## Deferred work

This release does not change the bootloader. Power-loss-safe storage replacement
and persistent installed-version markers require a separately designed
bootloader rollout and are deferred to 7.17. They are inherited risks rather
than regressions introduced by 7.14.3.
