# Firmware 7.15 release record

7.15 adds the full and Bitcoin-only products, Zcash Orchard support, Hive,
BIP-85, dice entropy, RNG health checks, and runtime clear-sign metadata. It
also carries the audited signing, storage, transport, session, and confirmation
fixes for this release line.

Runtime clear-sign identities live only in RAM and require Advanced Mode.
Decoded transaction context remains additive: the ordinary transaction review
still appears. Firmware 7.15 contains no pinned provider key and does not label
provider metadata as approved by KeepKey.

## Dependencies

- device-protocol: `27d3fa1f6215139cde6411f9a2882f36bb373fc9`
- python-keepkey: `b76ee610dd18934ee3aeeb36cfc541e8799eb46d`
- trezor-firmware: `8a392f70a5d5575ece3dfb35f115d4a4b27f497c`

The device-protocol and python-keepkey commits are shared by both release
branches. Their `.gitmodules` branches contain the pinned commits.

## Release gates

- Native firmware, board, crypto, and Pallas tests
- Python host integration against full and Bitcoin-only emulators
- ARM release builds for both products with the 16 KiB runtime SRAM floor
- Reproducible artifact manifest and checksum verification
- Secret scan, submodule validation, static analysis, and formatting
- Physical OLED and signed-upgrade checks before release signing

The canonical pull request records the exact-head CI runs and review status.

## Deferred work

This release does not change the bootloader. Power-loss-safe storage replacement
and persistent installed-version markers require a separately designed
bootloader rollout and are deferred to 7.17. They are inherited risks rather
than regressions introduced by 7.15.
